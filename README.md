# Weighted Least Squares (WLS) Regression with Python and statsmodels

Python scripts fitting weighted least squares (WLS) regression models with statsmodels for several variables, on Mariana Trench morphometry. Reusable statistical-modelling example.

## Scripts

- `sm_wls_maria.py`
- `sm_wls_max.py`
- `sm_wls_pacif.py`
- `sm_wls_phil.py`
- `sm_wls_sedim_thickness.py`
- `sm_wls_slope_angle.py`

## Data

- `Tab-Morph.csv`

## Requirements

Python 3 with `matplotlib`, `numpy`, `pandas`, `patsy`, `scipy`, `seaborn`, `statsmodels`.

```
pip install matplotlib numpy pandas patsy scipy seaborn statsmodels
```
